# نظام إدارة المشتريات — تطبيق أندرويد (APK)

كل مرة ترفع فيها تعديلاً إلى المستودع، يبني GitHub ملف APK جديداً تلقائياً
ويضعه في قسم **Releases** باسم `PurchaseManager.apk`.

## الإعداد (مرة واحدة)
1. أنشئ مستودعاً جديداً على github.com (اسمه مثلاً `purchases-app`).
2. ارفع محتويات هذا المجلد كاملة (بما فيها المجلد المخفي `.github`) إلى الفرع `main`.
3. افتح تبويب **Actions** وانتظر انتهاء «Build Android APK» (حوالي 5–8 دقائق). إن لم يبدأ، اضغط Run workflow.
4. افتح تبويب **Releases** ← `latest` ← حمّل `PurchaseManager.apk`.

## التثبيت على الجوال
- افتح رابط الـ Release من متصفح الجوال (سجّل الدخول إن كان المستودع Private)، حمّل الملف، وثبّته.
- اسمح بـ «التثبيت من مصادر غير معروفة» عندما يطلب الجوال ذلك.

## التحديث
- استبدل الملف `web/index.html` بالنسخة الجديدة (زر Edit أو Upload على GitHub) ← Commit.
- يُبنى APK جديد تلقائياً. ثبّته فوق القديم: **بياناتك لا تُمسح** لأن توقيع التطبيق ثابت.

## ملاحظات
- تصدير Excel/PDF من التطبيق يفتح قائمة المشاركة في الجوال لتختار «حفظ في الملفات» أو Drive أو واتساب.
- لتتطابق بيانات الجوال مع الكمبيوتر استخدم زر «المزامنة» بنفس رابط Firebase والرمز السري.
- إن فشل إنشاء الـ Release بسبب الصلاحيات: Settings ← Actions ← General ← Workflow permissions ← Read and write ← Save، ثم أعد تشغيل Run workflow.
